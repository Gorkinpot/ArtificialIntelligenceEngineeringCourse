# Ноутбуки проекта

В папке `notebooks/` лежат ноутбуки для анализа данных и сравнения моделей.

- `01_eda.ipynb` - разведочный анализ датасета `hotel_bookings.csv`
- `02_baselines.ipynb` - baseline-модели и сравнение метрик

Рекомендуемый порядок запуска:

1. Активировать виртуальное окружение проекта
2. Выбрать интерпретатор `project/.venv/Scripts/python.exe`
3. Запустить `01_eda.ipynb`
4. Затем запустить `02_baselines.ipynb`
