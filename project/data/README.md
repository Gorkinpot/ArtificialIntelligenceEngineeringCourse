# Данные проекта

## Что лежит в репозитории

- `hotel_bookings.csv` - основной датасет проекта.

Основной файл используется для обучения и экспериментов.

## Полный датасет

Целевой датасет проекта: **Hotel Booking Demand**.

Полный CSV уже можно использовать напрямую через путь в `configs/train.json`.

Ожидаемая схема включает колонку `is_canceled` и признаки, используемые в `src/data.py`.
